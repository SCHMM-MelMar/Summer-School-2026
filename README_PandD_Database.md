# Probes and Drugs simplified database


Here we have code for using the simplified Probes and Drugs database. 
There is a UML as a visualization of the simplified database.  

```pd_utils.py``` provides a way to query the database and has functions for queries by drugs and by target etc.
You can use the same code on the large sql Database.

Under ```noteboooks``` we have notebooks showcasing how to use the database in accordance to our use cases.
